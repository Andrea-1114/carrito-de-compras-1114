# 🛒 Carrito-de-Compras-1114 — AZcart

ZURY CARRILLO & ANDREA MORENO  
AZcart – Sistema Inteligente de Compras y Control de Presupuesto

---

##  Descripción del Proyecto

**AZcart** es una aplicación web interactiva diseñada para crear y organizar listas de compras de supermercado de forma fácil, rápida e intuitiva. 

El sistema cuenta con un **presupuesto máximo de $400.000 COP**. Cada vez que el usuario añade un producto, el programa descuenta automáticamente su valor del saldo disponible y calcula el gasto acumulado en tiempo real.

---

##  Características Principales

- **Control de Presupuesto:** Gestión dinámica de saldo en tiempo real sobre un tope de $400.000 COP con alertas de sobrepaso.
- **Categorización Completa:** Clasificación organizada en Frutas, Verduras, Lácteos, Carnes, Belleza e Higiene, Bebidas, Granos, Mascotas y Boutique.
- **Validación Anti-Duplicados:** Verificación automática para evitar ingresar productos repetidos en la lista.
- **Interfaz Interactiva:** Catálogo filtrable, búsqueda en tiempo real, ícono de carrito con contador, conmutador de modo claro/oscuro y componentes visuales avanzados.
- **Sincronización Backend:** Formulario de finalización de compra conectado con servidor Python para el registro de pedidos.

---

##  Tecnologías Utilizadas

- **Frontend:** HTML5, CSS3 (*Theme Black & Gold Imperial*), JavaScript (ES6+), SVG Canvas, Spline 3D Viewer.
- **Backend / BD:** Python (Flask), MySQL.
- **Herramientas:** Visual Studio Code, Git & GitHub.
